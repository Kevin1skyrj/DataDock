# Raycast Design Reference

## Purpose

Raycast is the primary inspiration for the DataDock application interface.

The objective is to capture its premium, desktop-inspired experience while creating an original product.

---

## Characteristics

- Minimal
- Premium
- Desktop-first
- Productivity focused
- Fast
- Clean
- Calm
- Elegant

---

## Visual Style

- Large whitespace
- Soft neutral colors
- Rounded corners
- Thin borders
- Layered cards
- Minimal shadows
- Strong typography hierarchy

---

## Components

Use Raycast as inspiration for:

- Sidebar
- Dashboard
- Navigation
- Settings
- Search
- Command Palette
- Cards

---

## Motion

Motion should be:

- Fast
- Responsive
- Subtle

Avoid dramatic animations.

---

## User Experience

Every interaction should feel immediate.

Reduce clicks.

Reduce distractions.

Prioritize productivity.

---

## Do Not Copy

- Layout
- Branding
- Logo
- Assets
- Icons

Capture the feeling, not the implementation.
