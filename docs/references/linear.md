# Linear Design Reference

## Purpose

Linear is the inspiration for productivity-focused interfaces.

---

## Characteristics

- Clean
- Efficient
- Dense but readable
- Professional

---

## Use For

- Dashboard
- Tables
- Data presentation
- Navigation
- Settings
- Productivity workflows

---

## Motion

Minimal.

Instant.

Functional.

---

## Avoid

Overly colorful interfaces.

Large decorative elements.

Unnecessary animations.
