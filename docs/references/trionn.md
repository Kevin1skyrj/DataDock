# Trionn Motion Reference

## Purpose

Trionn is the primary inspiration for the DataDock landing page animations.

It should influence storytelling and premium motion only.

Do not use this animation style inside the dashboard.

---

## Characteristics

- Premium
- Cinematic
- Smooth
- Elegant
- Storytelling

---

## Animation Style

Use GSAP for:

- Hero animations
- Scroll reveals
- Background movement
- Text reveals
- Section transitions
- Mouse interactions
- SVG animations

---

## Landing Page Goal

Visitors should immediately feel:

"This is a premium product."

---

## Dashboard

Do NOT use Trionn-style animations inside the dashboard.

Dashboard animations should remain fast and minimal.

---

## Rules

Animation should:

- Guide attention
- Improve storytelling
- Enhance the brand

Never animate for decoration.
